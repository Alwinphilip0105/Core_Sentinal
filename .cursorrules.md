# CoreSentinal Project Rules

## Tech Stack
- Language: Python 3.10+
- OS: Windows (target)
- Core Libraries: pywin32, win32clipboard, PyQt6, onnxruntime, transformers, faker
- Model: Quantized TinyBERT (INT8)

## Coding Standards
- prioritize performance: every clipboard check must complete under 100ms.
- Use 'win32gui' for message-only windows to listen for 'WM_CLIPBOARDUPDATE'.
- Prefer asynchronous or multi-threaded UI handling to prevent the Windows listener from hanging.
- Use 8-bit quantization for all ONNX model inference.

## UI/UX Guidelines
- Aesthetic: "Nano Banana" (Compact, minimalist, neon yellow #FFFF00 accents, charcoal gray #333333 backgrounds).
- Framework: PyQt6 for high-DPI transparent overlays.

## Security
- Privacy First: No clipboard data should ever be logged or transmitted off the local machine.
- All sanitization must happen in-memory.
