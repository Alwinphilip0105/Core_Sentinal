How Core Sentinel scans each paste

StepRole
1. Clipboard HookCaptures clipboard text when a supported AI app receives paste.
2. ChunkingSplits normalized text into overlapping inference windows.
3. Regex ScanMatches deterministic patterns for IDs, cards, secrets, and tokens.
4. spaCy NERExtracts PERSON, ORG, GPE, DATE, and MONEY spans for context.
5. TinyBERT ClassifierScores each window for contextual sensitive-content likelihood.
6. Risk AggregationFuses signals into a single score mapped to warn or block policy.
7. RemediationOffers redaction, reversible encryption, or audited override paths.
8. Active LearningQueues corrections for retraining without storing raw clipboard by default.

Inference latency: ~22ms per window. Zero clipboard data stored.
