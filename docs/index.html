How Core Sentinel scans each paste

01 Clipboard Hook ›
Captures clipboard text when a supported AI app receives paste.
02 Chunking ›
Splits normalized text into overlapping inference windows.
03 Regex Scan ›
Matches deterministic patterns for IDs, cards, secrets, and tokens.
04 spaCy NER ›
Extracts PERSON, ORG, GPE, DATE, and MONEY spans for context.
05 TinyBERT Classifier ›
Scores each window for contextual sensitive-content likelihood.
06 Risk Aggregation ›
Fuses signals into a single score mapped to warn or block policy.
07 Remediation ›
Offers redaction, reversible encryption, or audited override paths.
08 Active Learning ›
Queues corrections for retraining without storing raw clipboard by default.

Inference latency: ~22ms per window. Zero clipboard data stored.
