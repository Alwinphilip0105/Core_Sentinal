# Scripts (development helpers)

Run these from the **repository root** (with `core-sentinel-guardrail` on `PYTHONPATH` or using the project venv).

| Script | Purpose |
|--------|---------|
| `manual_probe.py` | Quick `infer.score_clipboard` examples |
| `check_dataset.py` | Dataset sanity checks |
| `eval_model.py` | Model evaluation utilities |
| `build_labeling_queue.py` | Labeling queue builder |
| `dataset_sources_report.py` | Dataset source report |
| `review_manual_errors.py` | Manual error review |

See **`../REPO_LAYOUT.md`** for how this folder fits the repo.
